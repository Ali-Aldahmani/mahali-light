# Bytecra POS — build assets

| File | Purpose |
|------|---------|
| `icon.png` | App icon (512×512); electron-builder generates `.ico` on Windows |
| `installer.nsh` | NSIS custom install/uninstall hooks |
| `icon.ico` | Optional; add a 256×256 ICO to override auto-conversion |
| `banner.bmp` | Optional NSIS header (493×58) |
| `dialog.bmp` | Optional NSIS sidebar (493×312) |

Replace `icon.png` with your final brand asset before a public release.
